### Funcionalidad
Skill desarrollada inicialmente con Skill Creator de Anthropic/Claude y posteriormente refinada a mano.
Responde a las 3 tareas solicitadas:
- Generar un escenario de atributo de calidad de 6 partes en base a una descripcion.
- Verificar completitud y corrige un escenario propuesto por el usuario.
- Armar un arbol de utilidad (utility tree) en base a descripciones o escenarios aportados por el usuario.
